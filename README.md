# ONE CLICK COMPUTERS Website

A responsive portfolio/business website built with plain HTML, CSS and JavaScript.

## Files
- index.html — main website
- css/style.css — all styling and responsive layout
- js/script.js — mobile menu, year and WhatsApp contact form
- images/ — place your logo and real project images here

## Before publishing
1. Replace the sample project cards with actual photos of your work.
2. Add your official logo to the header if you have one.
3. Confirm your address, phone number and opening hours.
4. Test all WhatsApp, Facebook, Instagram and email links.
5. Upload the folder to your hosting provider.

## Important
The contact form currently opens WhatsApp. It does not store submissions in a database.
